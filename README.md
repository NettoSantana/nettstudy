# NettStudy

Plataforma B2C da Nettsan para aprendizagem infantil com missões diárias de Português, Matemática e Leitura.

## Executar localmente

1. Crie e ative um ambiente virtual.
2. Instale as dependências com `pip install -r requirements.txt`.
3. Copie `.env.example` para `.env` e ajuste a chave secreta.
4. Execute `python app.py`.
5. Acesse `http://127.0.0.1:5000`.
